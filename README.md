# iris-eda-project
Exploratory Data Analysis of the Iris dataset using Python, Pandas, Matplotlib and Seaborn.
Exploratory Data Analysis (EDA) – Iris Dataset

1. Project Overview

This project performs Exploratory Data Analysis (EDA) on the Iris dataset using Python. The purpose is to understand the dataset, identify patterns and relationships, detect potential outliers, and visualize differences among Iris flower species.

2. Objectives

- Understand the structure of the dataset.
- Check missing values and duplicate records.
- Calculate summary statistics.
- Analyze correlations between numerical features.
- Create visualizations to identify patterns and relationships.
- Summarize the top three insights.

3. Dataset Description

The Iris dataset contains measurements of three Iris flower species:

- Setosa
- Versicolor
- Virginica

The dataset includes four numerical features:

- Sepal length
- Sepal width
- Petal length
- Petal width

4. Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

5. Data Cleaning

- Checked missing values in all columns.
- Identified duplicate records.
- Removed duplicate rows.
- Verified the data types of the columns.

The initial dataset contained 150 rows. One duplicate row was removed, leaving 149 rows and 5 columns.

6. Exploratory Data Analysis

The following analyses and visualizations were performed:

1. Missing-value analysis
2. Correlation heatmap
3. Sepal length distribution
4. Outlier detection using boxplots
5. Average petal length by species
6. Sepal length versus sepal width
7. Petal length versus petal width
8. Species distribution
9. Summary statistics by species

7. Top Three Insights

1. Petal length and petal width show a strong positive correlation.
2. Setosa has considerably smaller petal measurements than the other two species.
3. Petal measurements help distinguish the three Iris species.

8. Conclusion

The EDA process helped identify relationships between flower measurements and differences among Iris species. Visualizations and summary statistics provided useful insights into the dataset and demonstrated the importance of data exploration before further analysis.

9. How to Run

1. Download or clone this repository.
2. Open "iris_eda.ipynb" in Jupyter Notebook or Google Colab.
3. Install the required Python libraries if necessary.
4. Run the notebook cells in order.
