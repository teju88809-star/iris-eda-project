Deployment and Rollback Notes

1. Project Execution

This project is an Exploratory Data Analysis notebook for the Iris dataset.

The notebook can be executed using Google Colab or Jupyter Notebook.

2. Requirements

Install the dependencies listed in "requirements.txt":

pip install -r requirements.txt

3. Run the Notebook

1. Open "iris_dataset_insights.ipynb".
2. Open it in Google Colab or Jupyter Notebook.
3. Ensure the required libraries are installed.
4. Run the notebook cells in order.
5. Verify that the visualizations and observations are displayed.

4. Version Control

The project files are maintained in a public GitHub repository. Commits provide a history of changes.

5. Rollback Procedure

1. Open the repository on GitHub.
2. Open the notebook or file that needs to be restored.
3. View its file history.
4. Identify the previous working version.
5. Review the earlier version and restore the appropriate content.
6. Commit the restored version and verify that it works.

6. Verification Evidence

Add screenshots of the actual file history and rollback procedure after performing and verifying these steps.
